# Proyecto Módulo 6 - Despliegue Frontend

## URL de la Aplicación
Puedes visitar la aplicación desplegada y funcionando en el siguiente enlace: https://miproyecto-marcos.vercel.app/

## Descripción de la Aplicación
Esta es una aplicación web Frontend básica generada con React (Create React App). El proyecto sirve como práctica final para configurar y automatizar el despliegue continuo. El código fuente está alojado en un repositorio de GitHub que, mediante un webhook, notifica a la plataforma de despliegue cada vez que hay cambios en la rama principal.

## Instrucciones para un nuevo despliegue
Si se necesita desplegar este proyecto desde cero en otro entorno de Vercel, sigue estos pasos:
1. Haz un fork o clona este repositorio en tu propia cuenta de GitHub.
2. Inicia sesión en Vercel (https://vercel.com) y selecciona "Add New Project".
3. Vincula tu cuenta de GitHub y selecciona este repositorio.
4. En el apartado de configuración, mantén el "Framework Preset" en "Create React App".
5. Haz clic en "Deploy" y espera a que termine la compilación.
